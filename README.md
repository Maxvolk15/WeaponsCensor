## О проекте

**Weapon Censor** — это веб-приложение, которое автоматически находит оружие на фотографиях и скрывает его с помощью различных методов цензурирования.

### Возможности:

- **Автоматическая детекция** — находит пистолеты, ножи, винтовки с помощью обученной нейросети
- **Три метода цензуры:**
  - **Размытие (Gaussian Blur)** — с настраиваемой силой
  - **Пикселизация** — с настраиваемым размером пикселя
  - **Чёрный прямоугольник** — полностью скрывает объект
- **Drag-and-drop** — перетащите фото или выберите файл
- **Быстрая обработка** — ~10 мс на изображение

## Модель

### Архитектура
Для детекции оружия используется **YOLOv8 nano** — облегчённая версия модели YOLO (You Only Look Once), оптимизированная для быстрой работы.

### Датасет
Модель обучена на датасете **Weapon Detection Dataset** с Kaggle:

- **Датасет:** [mehmetcubukcu/weapon-detection](https://www.kaggle.com/datasets/mehmetcubukcu/weapon-detection)
- **Размер:** ~5000 изображений
- **Классы:** pistol, knife, smartphone, monedero, billete, tarjeta
- **Целевые классы оружия:** pistol, knife

### Результаты обучения

| Метрика | Значение |
|---------|----------|
| **mAP50** | 0.882 |
| **mAP50-95** | 0.701 |
| **Precision** | 0.819 |
| **Recall** | 0.812 |

По классам оружия:

| Класс | mAP50 |
|-------|-------|
| pistol | 0.913 |
| knife | 0.974 |

## Установка и запуск
Шаг 1: Клонирование репозитория
```bash
git clone https://github.com/your-username/weapon-censor.git
cd weapon-censor
```
Шаг 2: Создание виртуального окружения
Windows:

```bash
python -m venv venv
venv\Scripts\activate
```
Linux/Mac:

```bash
python3 -m venv venv
source venv/bin/activate
```
Шаг 3: Установка зависимостей
```bash
pip install -r requirements.txt
```

Шаг 4: Запуск приложения (в папке с файлом app.py)
```bash
flask run
```
